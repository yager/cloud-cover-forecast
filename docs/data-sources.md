## モデルの仕様

| モデル | 解像度 | 先まで | 刻み | 備考 |
|---|---|---|---|---|
| 気象庁MSM | 5km（0.0625°×0.05°） | 78時間（00/12UTC）、他は39時間 | 1時間 | 日本周辺のみ |
| ECMWF AIFS | 0.25°（約25km） | 15日 | 6時間 | ECMWF の AI モデル。2025年2月から正式運用 |
| 気象庁GSM（未使用） | 無料公開版は0.5°（約55km） | 11日 | 6時間 | 山では粗すぎるため採用せず |

**配信の遅れ**: MSM は初期時刻から3.5〜5時間、AIFS は約5.6時間（実測）。

**1コマのデータ量**: MSM は全要素で約800KB。全球モデルは1コマが GSM 8MB、AIFS 29MB あるため、面データとしては現実的ではありません（地点の時系列なら範囲指定で1変数1KB程度）。

## 気象業務法の整理

気象庁の[予報業務許可のFAQ](https://www.jma.go.jp/jma/kishou/minkan/q_a_o.html)より。

- 数値予報モデルの格子点値をそのまま表示すること自体は、予報業務の許可なしでできる。
- 「予報業務を行っていると誤解されないために、予報ではなく数値計算の結果であり、大きな誤差が含まれる可能性があること等を明示することを**推奨**」（義務ではなく、表示場所や回数の決まりもない）。
- **「予報と称して提供、表示する場合には独自の予報とみなされます」**。呼び方が決定的。
- **空間内挿や地形による補正等の加工**を行うと、独自の予報とみなされる可能性がある。

このサイトでの対応:

- モデルの計算値は「予測」、気象庁の発表は「予報」と呼び分ける。
- 格子は最近傍で塗り、補間・平滑化をしない。3層を合成した独自の指標（「星が見えるか」など）は作らない。
- 注意書きはフッターに1か所、各表の「ⓘ」に短く。
- **例外**: 気温は Open-Meteo の API が地点の標高に合わせて補正した値を使っている（ⓘ に明記）。生の格子値に戻す場合は `elevation=nan` を付ける。

## 検証の記録

**雲量タイルとの一致**（2026-09-21）

- ウェザーニューズの雲量タイルの中身は MSM の層別雲量そのもの。bounds がMSM格子の半マス外側と一致し、地点値も一致。
- ブラウザで描いた `CloudGridLayer` のタイルと、同じ時刻・同じ z5 タイルを画素単位で比較して RGBA 完全一致が 98.8〜99.9%。不一致の約97%は色の境目から2px以内（1マスが約3px）。
- 格子を半マスずらすと一致率が 89〜97% に落ちるため、格子の位置合わせは正しい。

**地点値の一致**

- 全国7地点の下層/中層/上層の雲量が、Open-Meteo API の値と完全一致（行0が南端、緯度 22.4+0.05·iy、経度 120+0.0625·ix）。

**天気コードとアイコン**

- 気象庁の天気コードとアイコンのファイル名は一致しない（118コード中88コードが別名。例: 211「曇後晴」→ `210.svg`）。対応表は気象庁の天気予報ページが持つ `TELOPS` から書き起こし、アイコン30種類すべての存在を確認済み。

**AIFS の降水量**

- API の1時間値は6時間ブロック内で同じ値が並ぶ。S3 の6時間合計とほぼ一致するため、**6時間の合計を1時間あたりに直した値**。表示はそのままでよく、割る必要はない。

**気圧痛のしきい値**

- 医学的な報告: 前日比で5hPa以上の低下があると頭痛が増える。標準の1013hPaから6〜10hPa低い1003〜1007hPaが悪化しやすい帯。
- 頭痛ーる・ウェザーニュースとも、具体的なしきい値は非公開。
- 実測（MSM、5地点・4日分）では、3時間で±3hPa以上動く時間は0〜2%しかなく、窓が短すぎると色が付かない。6時間で±2hPa、24時間で±5hPa を弱の基準にすると、穏やかな時期でも2〜3割の時間に「弱」が出て、中・強は荒天時だけに出る。

**週間予報の空欄**

- 気象庁の週間予報は、先頭の日だけ天気コード以外が空で配信される（その日は3日先までの予報が受け持つため）。信頼度は3日目以降にしか付かない。仕様どおりなので、そのまま「−」で表示している。
