# 潮位データ（気象庁 潮位表）

気象庁が公開している**潮位表掲載地点**と**年次テキスト**を同梱しています。1時間予測表の潮位行で使います。

| ファイル | 内容 |
|---|---|
| `stations.json` | 地点 id・名称・緯度経度 |
| `manifest.json` | 取得日時・年ごとの件数・欠落 |
| `{year}/{id}.txt` | その年の毎時潮位＋満干（気象庁テキストそのまま） |

## 周期と表示上の正規化

潮位表の値は、月・太陽の起潮力（引力の場所差＝潮汐力）を周期成分（**分潮**）の和として推算した**天文潮**です。気象モデルの雲量・気温とは別物です。

主要な分潮の周期（おおよそ）:

| 分潮 | 内容 | 周期 |
|---|---|---|
| M2 | 主太陰半日周潮 | **12時間25分** |
| S2 | 主太陽半日周潮 | 12時間 |
| K1 / O1 | 日周潮 | 約1日 |

多くの日本沿岸では半日周潮（または混合で半日周が強い）が卓越し、満→次の満は平均 **約12時間25分**です。太陰日に乗るため、満干時刻は暦日の 0 時では区切れず、**毎日だいたい50分ずれ**、山が日付をまたぐのも普通です。同じ日に高さの違う満潮・干潮が2つ来る**日潮不等**もあります。

そのため表の色分けでは、暦日の最大／最小ではなく、**M2 の半周期に相当する前後約±6時間**の局所窓で相対化し、中立付近を平常、窓内の山側を満・谷側を干として塗ります。段階は5つ（|s| の閾値 0.30 / 0.55 / 0.75 / 0.88 / 0.96）。UI では行ラベルを `潮位 *1`、地点名と距離は表下の脚注に出します（詳細は `docs/data-sources.md`）。

## 更新方法

```bash
python3 scripts/fetch_tide_data.py
# 年を指定する場合
python3 scripts/fetch_tide_data.py --years 2026,2027
```

GitHub Actions でも同じスクリプトを年1回（および手動）実行できます（`.github/workflows/fetch-tide-data.yml`）。

## 出典

- 地点一覧: https://www.data.jma.go.jp/kaiyou/db/tide/suisan/station.php
- テキスト: https://www.data.jma.go.jp/kaiyou/data/db/tide/suisan/txt/{year}/{id}.txt
- フォーマット: https://www.data.jma.go.jp/kaiyou/db/tide/suisan/readme.html

政府標準利用規約に従い、出典を明記して利用します。航海・安全の根拠には海上保安庁刊行の潮汐表を使ってください。ここは撮影計画の参考用です。気圧・風などの気象の影響で、実測は推算とずれることがあります。
