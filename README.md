# 雲量予想 / Cloud Cover Forecast

下層・中層・上層の雲量を同時に表示して判断を早められるようにしています。
初期表示は、作者の意向で関東地方を表示するようにしています。
スマホでは地図を縦に3段、PC（画面幅1000px以上）では横に3枚並べ、画面幅に応じて最大2倍まで拡大します。

## システム詳細

### 地図表示

- **地図ライブラリ**: Leaflet.js
  - Googleマップのように拡大縮小や移動がスムーズに実現できます。
- **地図タイル**: 国土地理院の写真地図（seamlessphoto）
  - `https://cyberjapandata.gsi.go.jp/xyz/seamlessphoto/{z}/{x}/{y}.jpg`
- **オーバーレイ**: 白地図（blank）を階調逆転して重ねる
  - `https://cyberjapandata.gsi.go.jp/xyz/blank/{z}/{x}/{y}.png`
  - CSS filter: `invert(1)` と `mix-blend-mode: lighten` を適用

### 雲量レイヤー

- **データ**: 気象庁メソモデル（MSM）の層別雲量（cloud_cover_low / mid / high）
  - Open-Meteo のオープンデータ（AWS, CC BY 4.0）の `data_spatial/jma_msm` を利用
  - `latest.json` から初期時刻と対象時刻の一覧を取得し、選択した時刻の `.om` ファイル（約800KB）を1回で読み込む
- **読み込み**: `@openmeteo/file-reader`（WebAssembly、GPL-2.0、版を固定して CDN から読み込み）
- **描画**: MSM の等緯度経度格子（経度0.0625°×緯度0.05°）を、地図の各画素に最も近い格子の値で塗る（`msm.js`）
  - 補間・平滑化はしない。数値計算結果をそのまま色分けする
  - 色分けは 20% 未満を透明とし、20 / 40 / 60 / 80 / 100% で区切る
- 気象業務法上、予報ではなく数値計算の結果であり大きな誤差を含み得る旨を画面に表示しています。

### 地点ピン（`pin.js`）

- 行きたい地点に赤いピンを1本立てられます。3つの地図すべてに同じ位置で表示し、どれかで動かすと他も追従します。
  - PC はクリック、スマホは長押しで置く。ドラッグで移動、操作パネルの「×」で消去
- 操作パネルに「📍地点名 上12 / 中40 / 下80%」の形で、表示中の時刻のピン地点（最も近い格子）の雲量を表示します。
- 場所検索（スマホは🔍ボタンで開く）
  - 地名・住所: 国土地理院の住所検索API（`https://msearch.gsi.go.jp/address-search/AddressSearch`）をブラウザから直接呼び、地図の中心から近い順に並べる。都道府県は addressCode の先頭2桁から付ける
  - 緯度経度: 十進（`35.68, 139.77`）・度分秒（`35°40'52"N 139°46'10"E`）・N/S/E/W 付きに対応。緯度と経度が逆でも日本付近になる方を採用（xLineMap の実装を移植）
- ピンは URL の `pin=緯度,経度`（検索で置いた場合は `pinname=地点名` も）に入ります。ブラウザには保存しません。

### 日の出・日の入り計算

- **ライブラリ**: SunCalc (https://github.com/mourner/suncalc)
- **計算対象**: ピンの地点（ピンが無いときは緯度35.844535、経度139.746094）における日の出・日の入り時刻
  - 日の出・日の入時刻に近い日時のプルダウンに表示します。

### 初期表示範囲

- 関東の緯度経度の範囲に合わせてズームを決めます（小数ズーム、0.25刻み）。地図が大きいPCでも表示範囲は同じです。
- URLパラメータ `lat` / `lng` / `z` があればそちらを優先します。

### 地図連動機能

3つの地図のズームレベルと位置を連動させ、1つの地図を操作すると他の2つの地図も同期します。
